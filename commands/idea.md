# /idea — Start Ideation Pipeline

**Usage:** `/idea [system/feature description]`

## What Happens

```
1. Activate: skills/ideation-to-plan/SKILL.md
2. CTO Agent analyzes → creates system design
3. PM Agent creates PRD → breaks into tasks
4. Tech Lead breaks down → assigns agents
5. Human checkpoint → approve/modify
6. Execution begins
```

## Examples
```
/idea I want to build a compliance verification system for document review
/idea Add real-time collaboration feature to the editor
/idea Build a customer support chatbot with RAG pipeline
```

## Input Tips
- More detail = better design
- Include: what the system does, who uses it, key constraints
- Attach business/technical documents if available
