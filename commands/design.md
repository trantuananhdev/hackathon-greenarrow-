# /design — Create System Design

**Usage:** `/design [feature/component name]`

## What Happens

```
1. CTO Agent reads requirements/context
2. Creates: architecture/system-design/[name].md
3. Creates ADRs for key decisions
4. Presents design for review
```

## Different from /idea
- `/idea` = full pipeline from concept to tasks
- `/design` = only the system design phase (no PRD, no task breakdown)
