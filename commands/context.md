# /context — Show Context Map

**Usage:** `/context`

## What Happens

```
1. Activate: skills/context-recovery/SKILL.md
2. Read state.json + context-map.md
3. Count active/blocked tasks
4. Check git status
5. Output structured context report
6. Suggest next action
```

## When to Use
- Starting new session
- Lost track of what's happening
- Need quick orientation
- "Where was I?"
